# RouterCloud Web UI upstream baseline

The initial frontend baseline is derived from the official Dufs v0.46.0
web assets.

Upstream project: sigoden/dufs
Upstream version: v0.46.0

Files imported as the compatibility baseline:

- assets/index.html
- assets/index.css
- assets/index.js
- assets/favicon.ico

The RouterCloud frontend will preserve the Dufs backend/API and security
semantics while replacing the visual presentation with the RouterCloud
Metro-inspired design.

Operational deployment remains separate from this source tree until the
custom frontend passes isolated functional and security validation.
