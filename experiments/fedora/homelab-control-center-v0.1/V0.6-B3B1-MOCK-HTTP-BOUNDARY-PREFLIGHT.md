## What this step actually does

- Adds `tools/v06_b3b_mock_http.py`, an **alternative** non-root *manual* Python HTTP lab that listens on **127.0.0.1:8790 only** when explicitly started with `--serve-mock-b3b1`. It never binds HCC's existing 8788, and neither V0.5 nor Caddy/Grafana is changed. Verify the port is unoccupied before any optional manual start.
- The single route is exact, literal `GET /api/dns-guard-history?window=1h|6h|24h|7d`. Strict Host must be `127.0.0.1:<actual local port>`; Origin if present must be identical HTTP origin; Sec-Fetch-Site must be absent, `none`, or `same-origin`. Request bodies, duplicate host/origin, encoded selector tricks, extra query parameters, redirects and unknown routes are rejected. HEAD/POST/PUT/DELETE rejected.
- **No VictoriaMetrics calls. No import or invocation of the B2 reader.** Each accepted request executes a fixed *mock* child solely to exercise cancellation mechanics. It returns a sanitized `UNKNOWN / MOCK_ONLY_SOURCE_NOT_CONNECTED` with empty `segments` and `gaps`. A malicious or malformed child response is **never** projected as observed coverage.
- The mock child is launched with a fixed argv (no shell), no input, no user-supplied file/query/hostname, and a **2-second child-process deadline** enforced by `subprocess.run(timeout=...)` which kills/reaps that child on timeout. This is **not** a bound for future real VictoriaMetrics queries or a complete HTTP request SLO. A source-integrated stage must separately establish a bounded total deadline including serialization/response delivery, memory/stream limits and cancellation of *all* source workers.
- Requests use at most **8 HTTP request handlers**, and a **single non-blocking history lock**. A second history request returns `503` without starting another mock worker. Unrelated invalid requests are not serialized behind the slow worker. Responses have bounded output, `no-store`, `nosniff`, closed connection and restrictive CSP.
- `--inspect` prints fixed limits without any network access. Neither `--inspect` nor importing this module starts a listener. Tests launch an ephemeral **loopback mock server** and mock process responses; no router, no VM source reads, no credentials, no logs, no writes to source/service configuration.
