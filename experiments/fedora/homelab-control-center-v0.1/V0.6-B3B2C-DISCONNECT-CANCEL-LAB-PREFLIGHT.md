## Scope and security boundary

- Add a wholly separate `tools/v06_b3b2c_disconnect_lab.py` with a read-only `--inspect` CLI and a bounded **internal synthetic sleep worker**. **No server-start CLI**, no import into B3B2B, V0.5 or B3C, no direct VM/ASUS/DNS contact. Merely importing or inspecting the module never creates a listener or child process.
- **Only unittest** binds `127.0.0.1` with an OS-assigned ephemeral port and instantiates the mock `SyntheticCancelHandler`. Its special `/__hcc_b3b2c_synthetic_cancel` route exists only in this test handler. It is NOT a B2/B3B2B HTTP endpoint or a new deployed API. Only literal local Host and optional same-origin Origin/Fetch-Site are accepted. Unknown routes or methods are denied without starting a worker.
- During a synthetic request, the handler starts a bounded child `python -B <this lab> --internal-mock-worker --sleep-ms <1..5000>` with fixed argv, no shell, no stdin/stdout/stderr pipes, and a new process group. Linux `poll(POLLRDHUP/POLLHUP/POLLERR/POLLNVAL)` checks the TCP peer every 50 ms without consuming application bytes. On detected disconnect or provisional six-second mock deadline, it kills the isolated process group and reaps the child. No client content or source labels are logged.
- **All non-disconnected responses say `UNKNOWN`** and expose only a fixed mock reason token, never positive coverage, DNS availability, transition details, or router power state. A disconnected client gets no second response attempt. The explicit mock route cannot query the seven B2 series.
- Linux `POLLRDHUP` also observes a **write-half-close**: the lab deliberately cancels conservatively, even when a peer may still be waiting to read. This mock experiment is **not** authentication, a complete HTTP delivery deadline, or a generic cross-platform disconnect proof. Socket readiness under reverse proxies, multiple clients, buffering, TCP edge cases and shutdown races requires a separate production-focused review.

## Test gate (zero real telemetry)

`tests/test_v06_b3b2c_disconnect_lab.py` tests strict no-network inspect, socket open/close without consuming request bytes, synthetic child normal exit, child failure, bounded mock timeout, kill/reap after disconnect, no spawn on pre-closed socket or invalid duration, rejected HTTP routes/methods/headers, one neutral mock HTTP response, real socket-close cancellation, and isolation from B2/VM. All network tests use ephemeral **localhost only**; no permanent listener or background service remains after tests.

```bash
cd experiments/fedora/homelab-control-center-v0.1
PYTHONDONTWRITEBYTECODE=1 python3 -B -m unittest discover -s tests -p 'test_v06_b3b2c_disconnect_lab.py' -v
PYTHONDONTWRITEBYTECODE=1 python3 -B -m unittest discover -s tests -p 'test_*.py'
node --test tests/*.mjs
python3 -B tools/v06_b3b2c_disconnect_lab.py --inspect
```

Run only on a pinned, non-root Fedora clone after exact-head GitHub CI, and capture exit codes. No new HCC UI, process, Caddy/Grafana config, router/Unbound/Pi-hole/DNS Guard commands, notifications or persistence.
