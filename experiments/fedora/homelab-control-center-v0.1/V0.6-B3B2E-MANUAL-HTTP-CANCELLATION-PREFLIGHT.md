## Implementation scope

- The **existing** manual-only `tools/v06_b3b2b_manual_http.py` handler now invokes the merged `v06_b3b2d_cancel_guard.read_b2_with_peer(window, socket)` after the same exact B3B1 Host/Origin/Fetch-Site/URL/body checks and the single in-flight history lock. This is the real wiring of B3B2D to the optional lab route, not merely the separate experimental proof handler.
- An abandoned connection is detected before starting a source child, during bounded stdout reception, while waiting for child exit and before the response is written. A detached child process group is killed/reaped; the disconnected client receives **no** attempted HTTP response. Linux `POLLRDHUP` also treats client write-half-close conservatively as a disconnect; this may reject some clients that only half-close their write direction.
- The existing **two explicit startup flags**, non-root, `127.0.0.1:8791` binding, fixed `1h|6h|24h|7d` windows, B2 fixed seven-series metric allowlist, provisional 12s child limit, 65,536-byte streaming stdout limit, 65,536-byte sanitized HTTP response cap, 2s socket-write operation timeout, eight-handler cap, one in-flight history read, no-store and fail-closed `UNKNOWN` semantics all remain. This is **not** a complete end-to-end HTTP latency SLO, a background service or authorization to contact the real source.
- Existing B3B2B tests are updated to mock **the new peer-aware function** rather than the old `read_b2_supervised` function. This matters: the acceptance suite must not inadvertently run any real B2 local VictoriaMetrics request. B3B2D synthetic proof tests remain intact. New `tests/test_v06_b3b2e_manual_abort.py` tests the **actual B3B2B handler**, using patched synthetic child argv with a true ephemeral local TCP close mid-child, lock release, no-stale-success, bad headers, 503 concurrency, 12s-like synthetic deadline shortened by mocking, malformed/oversized child output and no startup on import/inspect.
- V0.5 fixed 27-Oct archive and its live tiles are untouched, as are `127.0.0.1:8788`, B3B1 mock 8790, Caddy, Grafana, DNS Guard, Unbound, Pi-hole, Tailscale, ASUS and production services.
