## Implemented behavior

C adds a process boundary ahead of [A's metadata validation](V0.14.6A-SUPPLIED-JOURNAL-ENVELOPE-LAB.md)
and [B's disposable atomic import](V0.14.6B-DISPOSABLE-IMPORT-LAB.md).
It runs one fixed, owned Python producer, receives a bounded JSONL batch,
checks complete process success, then invokes B. A valid prefix followed by
an exit error, warning, timeout or incomplete final row never reaches B.
There is no incremental import or automatic retry.

The producer emits supplied synthetic bytes. **It is not journalctl or a
trusted journal reader.** Consistent fabricated metadata still passes A;
running it through a child grants no additional provenance. C does not add
a live command/path/UID/key option, journal access, cursor, receiver ACK,
transport, production store or service. A/B and frozen #338 code stay unchanged.

## Process contract

| Boundary | Implemented rule |
| --- | --- |
| Command | Fixed `sys.executable -I -B -c` test program; no shell or supplied code |
| Environment / descriptors | Explicit `LC_ALL=C`, `LANG=C`, `TZ=UTC`; `close_fds=True`, new session; no store FD passed |
| Fixture job | Strict exact types; bounded base64 JSON on stdin, at most 2 MiB |
| Streams | Concurrent nonblocking stdin/stdout/stderr through a selector; no unbounded `communicate()` capture |
| stdout | At most 1 MiB and 128 newline-terminated rows; reject a one-byte / one-row overflow in flight |
| stderr | At most 1 KiB buffered; any nonempty stderr is HOLD, including exit 0 |
| Completion | Both output EOFs, input sent, child exit 0, valid framing; A then validates all rows before B reads/writes state |
| Deadline | 2 seconds after `Popen` returns, including pipe transfer and exit wait |
| Failure / interruption | Kill running owned process group, wait/reap with a separate 1-second timeout, close all pipes; cleanup failure is explicit uncertainty |
| Publication | Existing B whole-state validation, cooperative lock, atomic replace and file/directory sync |

Buffers retain at most each stream limit plus one detection byte; the bounded
fixture job and Python objects are additional memory. This is trusted test
code, not an OS sandbox or a process-tree supervisor for arbitrary programs.
The fixed child creates no descendants. Process creation, OS scheduling,
kill/reap and filesystem calls have no hard whole-operation time guarantee.
An empty stdout batch is currently HOLD, not proof that a journal is empty.
The process collector checks framing; A remains responsible for JSON/UTF-8,
blank rows, metadata, time ordering, row sizes and classification.

No state is touched on a failed source, even if its prefix is otherwise valid.
After successful capture, A/B validation can still reject the batch/store.
B's post-replace sync uncertainty and all raw-message/store-loss limitations
remain. C does not add a durable receipt or source progress to B's receipt.
