# 2026-11-02 — DNS Guard Cron/Entware `dig` incident and controlled production fix

**Scope:** sanitized, date-scoped engineering checkpoint; **not a complete end-of-day inventory**. Production evidence below was reported by the operator from ASUS TUF-AX5400 (ASUSWRT-Merlin), not independently collected from the router by GitHub CI.

## 1. Symptom and diagnostic PR #350

DNS Guard v3.2's minute-by-minute Cron watchdog kept the configured local resolver and performed its UDP readiness checks, but repeatedly skipped the optional active TCP probe. The original warning claimed that `dig` was installed but not runnable, although direct `/opt/bin/dig -v` and manually invoked `dns-guard ready` passed.

[PR #350](https://github.com/wojko6/Advanced-ASUS-Edge-Gateway-ZTNA-Infrastructure/pull/350) was validated by CI and squash-merged as `35cec505258aad3f6887de362215c120443427ff`. It logged the real preflight return code without altering fail-open semantics. After checksum-verified, operator-attended installation and an on-router backup, the scheduled task reported `dig preflight failed (rc=1); TCP probe skipped` each minute.

## 2. Root cause reproduced on the router

The firmware `crond` environment inherited `LD_LIBRARY_PATH=/lib:/usr/lib:/lib/aarch64`. Controlled, read-only `dig -v` comparisons established:

| Environment | Result |
| --- | --- |
| Clean environment | `DiG 9.20.18`, rc=0 |
| Firmware Cron library path | rc=1, `/lib/libc.so.6: version 'GLIBC_2.27' not found` (required by `/opt/lib/libisccfg-9.20.18.so`) |
| Entware `/opt/lib` prepended to inherited path | `DiG 9.20.18`, rc=0 |

The loader selected incompatible firmware GLIBC for an Entware library. The same per-command correction yielded a successful **real TCP DNS** lookup against the local Pi-hole (`one.one.one.one` → `1.0.0.1`, `1.1.1.1`), rc=0. This distinguishes a binary loader failure from DNS server failure.

## 3. Fix PR #351 and controlled deployment

[PR #351](https://github.com/wojko6/Advanced-ASUS-Edge-Gateway-ZTNA-Infrastructure/pull/351) was CI-validated and squash-merged as `87474fc596299e854e2b3688edaf68eccc240b26`. The fix prepends `/opt/lib` **only to the preflight and TCP `dig` invocations**, preserving the inherited library path for them and leaving global firmware environment, DNS policy, watchdog timing, Pi-hole and Unbound unchanged. A synthetic test reproduces the Cron ABI mismatch and checks that TCP is attempted.

The operator preserved the PR #350 version in an independently verified local backup and on-router backup, then staged, SHA256-checked and atomically installed PR #351. Active production SHA256 was verified as `a51f3dc9f3e21106e09fb69472a1c8b6e32864ba19cabd48b989d7515b2c84c7`. No router/service/WAN restart was performed for this patch.
