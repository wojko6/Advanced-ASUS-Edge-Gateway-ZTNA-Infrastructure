## Privilege and deployment boundaries

The desktop UI can execute **limited, allowlisted user-session actions**, with extra consent for approved mutations. **Do not conflate this with the separate C.63 Local AI Agent** whose published laboratory gate remains `MODEL_ACTION_AUTHORITY=NONE`. The GUI has not been independently security-audited, and its tool/approval code is absent from this repository. Reading files may expose contents to the local model; GUI app launches have indirect side effects. Arbitrary shell/`sudo`, autonomous router action, arbitrary file edits/deletes, and Wayland input control are not authorized.

No ASUS production update, HCC permanent deployment or autonomous-agent rollout was performed as part of this UI work. **`DEPLOYMENT_GATE=HOLD`** for the agent/HCC tracks.
