# Case studies

This directory is the canonical home for public project case studies.

The higher-level [case study index](../CASE-STUDIES.md) provides the curated
portfolio order and a short description of each investigation.

Historical paths under `docs/` are retained as compatibility pointers where
they were previously public. Operational checkpoints and supporting evidence
remain in their purpose-specific locations instead of being duplicated here.

Case studies should preserve four distinctions:

1. observed evidence;
2. remediation or design change;
3. validation;
4. interpretation and claim boundaries.

Deployment-specific secrets, public addresses, device identifiers and other
unnecessary infrastructure identifiers must remain excluded from public
case-study material.
